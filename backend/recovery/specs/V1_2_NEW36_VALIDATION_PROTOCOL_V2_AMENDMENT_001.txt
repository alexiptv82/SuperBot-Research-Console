type7_quantile(abs(s[TZ_threshold_domain]),q)

count(T0_threshold_domain)

count(TZ_threshold_domain)

threshold_domain_finite_n-threshold_domain_nonzero_n

zero_fraction=
NULL if threshold_domain_finite_n==0;
otherwise zero_n/threshold_domain_finite_n

ZERO_FREE_CONTROL

else if T0_threshold != TZ_threshold using exact Python value equality
with NULL==NULL treated as equal:
HZ_DISCRIMINATING

else:
HZ_NONDISCRIMINATING_EQUAL_THRESHOLD

A5. HB PRE-OVERLAP FAMILY MATRIX

================================================================

HB variants B0 and B1 operate on the SAME frozen baseline
pre-overlap set for each family.
Only the overlap inequality differs.

HB quantile=0.90

HB family=bitget_ofi:

signal=FEATURE_MAP[bitget_ofi]
domain=quality_admissible AND isfinite(signal)
threshold=type7_quantile(abs(signal[domain]),0.90)

pre_overlap=
domain
AND signal!=0.0
AND abs(signal)>=threshold
AND isfinite(forward_return)

direction=sign(signal)

This is the frozen baseline/T0 threshold domain.
It is NOT the TZ threshold domain.

HB family=depth_imbalance_l1:

signal=FEATURE_MAP[depth_imbalance_l1]
domain=quality_admissible AND isfinite(signal)
threshold=type7_quantile(abs(signal[domain]),0.90)

pre_overlap=
domain
AND signal!=0.0
AND abs(signal)>=threshold
AND isfinite(forward_return)

direction=sign(signal)

This is the frozen baseline/T0 threshold domain.
It is NOT the TZ threshold domain.

HB family=depthL1_extOFI:

derived_domain=
quality_admissible
AND isfinite(z_di_l1)
AND isfinite(z_ext_ofi)

D=(z_di_l1+z_ext_ofi)/2

threshold=type7_quantile(abs(D[derived_domain]),0.90)

pre_overlap=
derived_domain
AND D!=0.0
AND abs(D)>=threshold
AND isfinite(forward_return)

direction=sign(D)

HB depthL1_extOFI therefore uses the frozen G0/V1.1 baseline
pre-overlap semantics, NOT G1.

HB family=gap_depthL1:

gap=bitget_gap_to_fair_bps
di_l1=bitget_depth_imbalance_l1

threshold_domain=
quality_admissible AND isfinite(gap)

threshold=type7_quantile(abs(gap[threshold_domain]),0.90)

pre_overlap=
threshold_domain
AND isfinite(di_l1)
AND gap!=0.0
AND abs(gap)>=threshold
AND di_l1!=0.0
AND sign(di_l1)==-sign(gap)
AND isfinite(forward_return)

direction=-sign(gap)

HB family=gap_localOFI:

fair_ofi_alignment=bitget_fair_ofi_alignment

threshold_domain=
quality_admissible AND isfinite(gap)

threshold=type7_quantile(abs(gap[threshold_domain]),0.90)

pre_overlap=
threshold_domain
AND isfinite(fair_ofi_alignment)
AND gap!=0.0
AND abs(gap)>=threshold
AND fair_ofi_alignment==1.0
AND isfinite(forward_return)

AND abs(gap)>=threshold
AND D_ext!=0.0
AND sign(D_ext)==-sign(gap)
AND isfinite(forward_return)

direction=-sign(gap)

HB gap_depth_extOFI therefore uses frozen C0/V1.1 baseline
pre-overlap semantics, NOT C1.

A6. EXACT-SPACING PRECEDENCE

================================================================

For V2, the normative definition is the frozen candidate definition:

exact_spacing_pair_n=
count of consecutive pairs in the sorted pre-overlap positions array
whose difference equals spacing_steps

Equivalent:

sum(
positions[i+1]-positions[i]==spacing_steps
for i in range(len(positions)-1)
)

The older Stage3 diagnostic implementation that counted all unordered
pairs at exact spacing is NOT normative for V2.

V2/candidate consecutive-pair semantics prevail.
